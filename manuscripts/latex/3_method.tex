\section{Methodology}
The REIGN framework consists of four primary stages.

\subsection{Preprocessing}
Data normalization and missing value imputation.

\subsection{Regime Detection}
Identifying structural breaks using the PELT algorithm.

\subsection{LLM-Augmented Priors}
Extracting structural priors from Large Language Models via prompt engineering.

\subsection{Neural Granger Engine (CUTS+)}
A coarse-to-fine message passing GNN architecture constrained by an Augmented Lagrangian to enforce acyclicity.

\subsection{Confidence-Weighted Ensemble}
Aggregating regime-specific DAGs into a global causal structure.
